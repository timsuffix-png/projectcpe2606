# คู่มือการเริ่มต้นใช้งานระบบ Gateway
### ระบบการตรวจสอบคุณภาพสินค้าและการบันทึกข้อมูลแนวโน้มอุณหภูมิ

ยินดีต้อนรับท่านเข้าสู่การใช้งานระบบ **Gateway** แอปพลิเคชันนี้ถูกพัฒนาขึ้นเพื่อใช้เป็นเครื่องมือหลักในการตรวจสอบมาตรฐานความปลอดภัยของผลิตภัณฑ์ (Quality Control) และการบันทึกข้อมูลความร้อนแบบเรียลไทม์ (Temperature Monitoring) เพื่อสนับสนุนกระบวนการตัดสินใจในสายการผลิต

---

## 1. การเตรียมความพร้อมก่อนการใช้งาน (Getting Started)
เพื่อให้แอปพลิเคชันทำงานได้เต็มประสิทธิภาพ ท่านควรตรวจสอบความพร้อมดังนี้:
1.  **การเชื่อมต่อ:** ตรวจสอบการเชื่อมต่ออุปกรณ์อ่านค่า (Gateway) ผ่านพอร์ต Serial (Arduino/Thermostat)
2.  **สิทธิ์เอกสาร:** เตรียมชื่อผู้ใช้งานและรหัสผ่านสำหรับการเข้าถึงฐานข้อมูลส่วนกลาง

---

## 2. ขั้นตอนการใช้งานหลัก (Core Workflows)

### 2.1 การเข้าสู่ระบบและการนำทาง
*   **Authentication:** การเข้าสู่ระบบจะช่วยป้องกันข้อมูลที่สำคัญ ท่านสามารถล็อกอินได้ที่หน้าแรกของโปรแกรม
*   **Navigation:** ใช้เมนูด้านข้าง (Sidebar) เพื่อเปลี่ยนโหมดการทำงานระหว่างการตรวจสอบสินค้า (QC) และการติดตามอุณหภูมิ (Thermostat)

### 2.2 การตรวจสอบคุณภาพสินค้า (Inspection Dashboard)
*   **Summary:** หน้าจอหลักจะแสดงผลสรุปในรูปแบบเปอร์เซ็นต์ (ความคืบหน้าการตรวจสอบ)
*   **Search:** ท่านสามารถค้นหาผลการตรวจสอบย้อนหลังได้โดยใช้ "รหัสสินค้า" หรือ "วัตถุดิบ" ในช่องค้นหา
*   **Data View:** กดที่ปุ่ม "รายละเอียด" (ไอคอนสีส้ม) เพื่อตรวจสอบค่าคงที่ที่พบบนชิ้นงานแต่ละชิ้น

### 2.3 การจัดการการทดสอบและโครงการ (Management)
สำหรับผู้ควบคุมระบบ สามารถเข้าถึงฟังก์ชันระดับการจัดการได้ดังนี้:
*   **Test Setting:** กำหนดมาตรฐานหรือเครื่องมือที่ใช้ในการวัดผลในแต่ละโปรเจกต์
*   **Project Test:** การรวมกลุ่มข้อมูลการทดสอบเข้าไว้ด้วยกันตามลอตการผลิตหรือตามคำสั่งซื้อ

---

## 3. การติดตามอุณหภูมิ (Temperature Monitoring)
ในกรณีที่ต้องการตรวจสอบเสถียรภาพความร้อน:
1.  เลือกเมนู **Thermostat** จากแถบเมนูด้านข้าง
2.  ระบบจะแสดงกราฟแนวโน้มอุณหภูมิ เพื่อวิเคราะห์ว่าค่าที่วัดได้อยู่ในเกณฑ์มาตรฐานที่กำหนดไว้ใน **Test Setting** หรือไม่

---

## 4. ข้อควรระวังและการแก้ไขปัญหาพื้นฐาน
*   **ข้อมูลหาไม่พบ:** ตรวจสอบว่าท่านได้เลือก "ชื่อโปรเจกต์" ที่ถูกต้องแล้วหรือไม่
*   **การเชื่อมต่อผิดพลาด:** หากกราฟอุณหภูมิไม่แสดงผล ให้ตรวจสอบการเชื่อมต่อพอร์ต USB ที่เมนูตั้งค่าพอร์ต (System Settings)
*   **แอปพลิเคชันไม่ทำงานร่วมกับข้อมูล:** ตรวจสอบสถานะของ Server API ผ่านผู้ดูแลระบบ

# ลำดับการทำงานและแผนผังส่วนติดต่อผู้ใช้ (Detailed Application Flow & Interface Mapping)

## 1. หน้าเข้าสู่ระบบ (Login Page)
*   **Input Fields:**
    *   `Username`: ระบุชื่อผู้ใช้งาน
    *   `Password`: ระบุรหัสผ่าน
*   **Button:**
    *   `Login`: ตรวจสอบสิทธิ์และนำทางไปยังหน้า **"การตรวจสอบคุณภาพสินค้า (QC Dashboard)"**

---

## 2. แถบเมนูด้านข้าง (Sidebar - Global Navigation)
*   **รายการหลัก:**
    *   `QC`: นำทางไปยังหน้า **"การตรวจสอบคุณภาพสินค้า"**
    *   `Thermostat`: นำทางไปยังหน้า **"ระบบติดตามอุณหภูมิ (Real-time)"**
*   **ส่วนท้าย (Bottom Icons):**
    *   `ไอคอนรูปเฟือง (Settings)`: นำทางไปยังหน้า **"ตั้งค่าระบบ"** (เช่น API URL)
    *   `ไอคอนออกจากระบบ (Logout)`: เคลียร์เซสชันและกลับไปที่หน้า **Login**

---

## 3. หน้าการตรวจสอบคุณภาพสินค้า (Inspection Dashboard)
*   **Buttons:**
    *   `ตั้งค่าการทดสอบ`: นำทางไปยังหน้า **"รายการตั้งค่าการทดสอบ (Test Setting List)"**
    *   `โปรเจกต์การทดสอบ`: นำทางไปยังหน้า **"รายการโปรเจกต์ (QC Project List)"**
*   **Search Input:**
    *   ช่องค้นหา: ระบุรหัสสินค้าเพื่อกรองข้อมูลในตารางผลการตรวจสอบ
*   **Table Actions (ในตาราง):**
    *   `ไอคอนวงกลมสีส้ม (Info)`: กดเพื่อไปหน้า **"รายละเอียดการตรวจสอบ (Inspection Detail)"** ของสินค้าชิ้นนั้นๆ

---

## 4. หน้าตั้งค่าการทดสอบ (Test Setting Management)
### 4.1 หน้าแสดงรายการ (List)
*   **Button:**
    *   `ย้อนกลับ`: กลับไปหน้า Dashboard
    *   `สร้าง`: นำทางไปยังหน้า **"สร้างการทดสอบใหม่ (Create Test Setting)"**
*   **Table Actions:**
    *   `ไอคอนแก้ไข (Edit)`: ไปหน้า **"แก้ไขการทดสอบ"**
    *   `ไอคอนถังขยะ (Delete)`: แสดงคำถามยืนยัน (Swal) เพื่อลบข้อมูลการตั้งค่า

### 4.2 หน้าสร้าง/แก้ไข (Create/Edit)
*   **Dropdown:**
    *   `ประเภทการทดสอบ`: เลือกประเภทของเครื่องมือ (เช่น *Thermostat* หรือ *Seaward*) ซึ่งจะทำให้ช่องกรอกข้อมูลด้านล่างเปลี่ยนไปตามประเภทที่เลือก
*   **Buttons:**
    *   `จัดการประเภทการทดสอบ`: นามทางไปยังหน้าจัดการประเภท (QC Type) เพื่อเพิ่ม/ลบประเภทเครื่องมือ
    *   `ตั้งค่า Sensor` (เฉพาะประเภท Thermostat): เปิดหน้าต่าง Popup เพื่อตั้งค่าไฟล์ Calibrate (Calibration)
    *   `สร้าง / บันทึก`: บันทึกข้อมูลลงฐานข้อมูลและรีโหลดหน้า

---

## 5. หน้าโปรเจกต์การทดสอบ (QC Project Management)
*   **Button:**
    *   `สร้าง`: นำทางไปยังหน้า **"สร้างโปรเจกต์การทดสอบ"** (ใช้สำหรับจับคู่การตั้งค่าหลายๆ อย่างเข้าด้วยกันเป็นโปรเจกต์เดียว)
*   **Table Actions:**
    *   `ไอคอนถังขยะ (Delete)`: ลบโปรเจกต์ (ข้อมูลการทดสอบที่เกี่ยวข้องจะถูกลบด้วย)

---

## 6.หน้าระบบติดตามอุณหภูมิ (Thermostat/Temperature Monitoring)
เป็นหน้าหลักสำหรับการทำงานกับเครื่องมือจริง
*   **Top Bar (Inputs & Selects):**
    *   `Thermostat Port`: ปุ่ม **"เลือก/เปลี่ยน"** เพื่อเลือกพอร์ต Serial (COM Port) ที่เชื่อมต่อกับอุปกรณ์
    *   `โปรเจกต์การทดสอบ (Dropdown)`: เลือกโปรเจกต์ที่ต้องการใช้งาน เพื่อให้ระบบดึงเกณฑ์การวัดผล (Script) มาใช้
    *   `รหัสสินค้า (Input)`: ระบุ Serial Number ของสินค้าที่จะเริ่มทดสอบ
*   **Table (Test History):**
    *   แสดงประวัติการทดสอบของสินค้านั้นๆ และมี **Checkbox** ให้เลือกหากต้องการเปรียบเทียบหรือดูข้อมูลเก่า
*   **Visual Interface:**
    *   แสดงสถานะอุณหภูมิ 4 จุดบนภาพจำลองเตารีดแบบ Real-time
*   **Action Buttons:**
    *   `ปุ่มทดสอบ`: เริ่มการทดสอบตามสคริปต์ที่ตั้งไว้ (จะส่งคำสั่งไปยังพอร์ต Serial)
    *   `ปุ่มหยุด`: หยุดกระบวนการทดสอบทันที

---

## 7. หน้าระบบตั้งค่า (System Settings)
*   **Input Field:**
    *   `API Path`: สำหรับระบุ URL ของเซิร์ฟเวอร์เพื่อให้โปรเจกต์เชื่อมต่อข้อมูลได้ถูกต้อง
*   **Button:**
    *   `บันทึก`: บันทึกค่าลงลอคอลคอนฟิกของระบบ (config.cnf)

---

## 8. ตรรกะการแสดงสถานะ (Status Logic)
เพื่อความเข้าใจที่ตรงกันในการดูรายงานผล ระบบมีเกณฑ์การแสดงสถานะดังนี้:

*   **รอการตรวจสอบ / ดำเนินการ (In Progress):** 
    *   จะแสดงสถานะนี้เมื่อสินค้ามีหัวข้อการทดสอบ **มากกว่า 1 หัวข้อ** (เช่น ในโปรเจกต์ต้องทดสอบทั้ง Seaward และ Thermostat)
    *   หากท่านทดสอบเสร็จเพียงอย่างเดียว สถานะรวมจะยังคงค้างเป็น "ดำเนินการ" เพื่อระบุว่ายังเหลืองานที่ต้องทำค้างอยู่
*   **ผ่าน / ไม่ผ่าน (Passed/Failed):** 
    *   จะแสดงสถานะนี้เมื่อ **การทดสอบครบทุกหัวข้อ** ตามที่โปรเจกต์กำหนดไว้แล้วเท่านั้น
    *   ในกรณีที่โปรเจกต์มี **เพียงหัวข้อเดียว** (เช่น มีแค่ Thermostat) เมื่อทดสอบเสร็จ ระบบจะสรุปผลเป็น Pass/Fail ทันที และข้อมูลจะย้ายออกจากรายการที่ "รอดำเนินการ" ไปอยู่ในประวัติที่สมบูรณ์แล้ว

---

### สรุปการเชื่อมโยง (Key Linkages)
1. **การตั้งค่า -> การรัน:** คุณต้องตั้งค่าในหน้า **Test Setting** ก่อน จากนั้นจึงไปสร้าง **QC Project** แล้วสุดท้ายจึงมาเลือกใช้งานในหน้า **Thermostat** เพื่อทำการทดสอบจริง
2. **การรัน -> รายงาน:** เมื่อมีการทดสอบในหน้า **Thermostat** ข้อมูลจะถูกบันทึกและย้อนกลับไปแสดงผลในหน้าตารางของ **Inspection Dashboard** เพื่อให้ผู้บริหารหรือผู้ควบคุมดูภาพรวมได้ครับ
